# UI 需求清单 — NovaWatchS12

> 本清单是用户交给 agent 的需求文件（配合概念图使用）。本工程没有外部概念图，
> 需求以「仿 Apple Watch Series 12 全功能 UI」文字描述 + 公开常识性布局经验
> 直接给出；所有视觉资产均为原创绘制（Lucide 线性图标 + 自绘 SVG），
> 不复制 Apple 任何位图/字体/图形资产。

---

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 项目名 | `NovaWatchS12` |
| 概念图 | 无（文字需求 + Apple Watch 公开设计语言描述） |
| 面板尺寸 | `456 × 456` px（Series 12 46mm 级别；2px ≈ 1dp 即 228dp） |
| 形状 | `CIRCLE`（半径 228，内容安全区 r≤216） |
| 用途一句话 | 智能手表全功能表盘 + 应用网格 + 健康/天气/闹钟/秒表/呼吸/AI 语音 |
| 交付物 | SquareLine 工程（.spj）+ 反渲染预览 |
| LVGL 版本 | `9.2.2` |

## 2. 屏幕清单与切换逻辑

| # | 屏幕名 | 一句话说明 | 怎么进入 | 怎么离开 |
| - | ------ | ---------- | -------- | -------- |
| 1 | `watchface` | 模拟表盘（指针+数字时间+ complications） | 开机默认 / 右滑 | 左滑 → `apps` |
| 2 | `apps` | 径向应用网格（8 图标环形排布） | watchface 左滑 / 表盘点 complication | 右滑回表盘；点图标进对应应用 |
| 3 | `health` | 健身三环 + 活动数据 | apps 点健康图标 | 右滑返回 apps |
| 4 | `weather` | 当前温度大字 + 逐时预报 | apps 点天气图标 | 右滑返回 apps |
| 5 | `alarms` | 闹钟开关列表 | apps 点闹钟图标 | 右滑返回 apps |
| 6 | `workout` | 体能训练启动页（户外跑步） | apps 点训练图标 | 右滑返回 apps |
| 7 | `stopwatch` | 秒表（大数字 + 头部按钮） | apps 点秒表图标 | 右滑返回 apps |
| 8 | `breathe` | 呼吸圆环动画 | apps 点正念图标 | 右滑返回 apps |
| 9 | `voice` | AI 语音（波形三态） | apps 点 AI 图标 | 叹号点击返回 |

- 初始屏：`watchface`
- 特殊切换：`voice` 屏三态（待机/聆听/播报）由对象显隐实现；swipe 环覆盖
  watchface↔apps，其余屏独立进出 apps。

## 3. 每块屏上有什么（逐屏粗排）

### 3.1 `watchface`
| 元素 | 内容 / 要求 | 大致位置 |
| ---- | ----------- | -------- |
| 表盘底 | 预烘焙 PNG（表圈+刻度+三针 10:09:30 姿态） | 居中满幅 |
| 数字时间 | `10:09` 大字 | 中上 |
| 日期 | `周二 9月28日` | 数字时间下 |
| complications | 心率/温度/电量 三组图标+数字 | 上/左下/右下 |
| 提示 | 左滑箭头 | 底部 |

### 3.2 `apps`
| 元素 | 内容/要求 | 大致位置 |
| ---- | --------- | -------- |
| 8 个应用图标 | 64px 环形 r=150，避开顶部状态区 | 径向环 |
| 中央 | Nova 徽标（自绘星形） | 居中 |

### 3.3–3.9 应用屏
健康=三环+步数/心率/卡路里；天气=大温度+4 个逐时段；闹钟=3 行开关卡；
训练=图标+户外跑步+开始按钮；秒表=大数字+开始/计次按钮；呼吸=圆环+「呼吸」
提示；语音=波形图+三态提示文案。

## 4. 交互与动画效果

| 挂在哪 | 事件 | 效果 |
| ------ | ---- | ---- |
| watchface ↔ apps | 手势 | CHANGE_SCREEN 滑动环 |
| apps 各图标 | 点击 | CHANGE_SCREEN 对应屏 |
| alarms 三行 | 点击 | 开关卡片文字切换（SHOW/HIDE） |
| breathe 圆环 | 进屏 | 透明度呼吸动画（loop_infinite） |
| voice | 点击麦克风 | 三态切换（SHOW/HIDE 波形+文案） |
| 秒表 | 进屏 | 大数字透明度脉冲一次 |

- 全局动画风格：克制，仅透明度渐隐渐现。
- 页面切换：`FADE_ON`，150ms。
