# AIWatch Apple 版 UI 设计规格文档（240×240 圆形屏）

圆形屏 **240×240**（SquareLine `shape: CIRCLE`），参照 Apple Watch 圆形表盘。
参考图：聊天附件（7 屏 Apple 风格）。画布中心 (120,120)，有效直径 240。

> **圆形裁剪规则**：所有内容必须落在内切圆内；四角（r>120 区域）不放任何
> 可交互元素或关键文本。安全区：以中心为圆心 r≤112 的圆内为内容区，
> 112<r≤120 只放贴边装饰（刻度、分页点）。
>
> 尺寸体系：正文 20px、标签 16–18px、页标题 22px、大数字 40px、超大时间 56px、
> 最小触控目标 44px、图标圆 44–48px。文本层级用 opacity：次级 0.62、三级 0.38。

## 屏幕（7 屏）

### 1. home（App 网格）
- 顶部：时间 `10:09`（20px，y=14，居中）+ 电池（右 x=196 y=16，18×10）
- 3×3 圆形图标网格，圆 44px；列中心 x=63/120/177，行顶 y=52/112/172
  - r1: 时钟(白底黑针) / 天气(蓝) / 心率(红)
  - r2: 跑步(绿) / Gemini(蓝紫渐变) / 设置(灰)
  - r3: 网格点(深灰 `#2C2C2E`) / 音乐(粉) / 消息(蓝)
- 分页点 y=212：4 点 x=104..134，第 1 点白，余 `#5A5A5A`
- 事件：点圆 → CHANGE SCREEN（music/message/grid 无对应屏则无动作或回自身）

### 2. clock（模拟表盘）
- 蓝色刻度贴边：r≈112，12 刻度（4 主 8 副）
- 大时间 `10:09`（56px，y=52，居中）+ `周二 4月22日`（16px 次级，y=116，居中）
- 指针：时针 32px 白 5px 宽、分针 46px 白 3px、秒针 50px 蓝 2px，轴心 (120,152)
- 轴心蓝点 8px；底部脚印图标 + `7532`（18px，y=206，居中，次级）

### 3. weather（天气）
- 顶部：📍(16px 黄) + `旧金山`（18px，x=36 y=16）
- 主图标 64px（x=28 y=52）+ `22°C`（40px 数字，右对齐 x=212，y=60）
- `局部多云`（20px，x=24 y=128）
- `最高 24° 最低 16°`（16px 次级，y=156）
- 底部逐时卡片：x=16 y=184 w=208 h=48，圆角 14，`rgba(255,255,255,0.06)`：
  4 列（图标 24px + 温度 14px），列中心 x=42/94/146/198
- 事件：点主区循环 8 种天气（叠层切换）

### 4. health（健康）
- 顶部：红心 24px（x=24 y=16）+ `72`（40px）+ `bpm`（14px 三级）
- 心率波形 192×56（x=24 y=66，PNG）
- 3 行数据（行高 34，y=134/172/210，x=16 w=208）：
  图标圆 22px + 标签 16px + 值 16px 右对齐
  - SpO₂ 98%（红/水滴）、体温 36.5°C（青/温度计）、睡眠 7小时48分（紫/月亮）

### 5. steps（计步）
- 顶部跑步人 24px（居中 y=12）
- 活动环 120px（中心 (120,118)），进度 94%，绿，环宽 12
- 环内：`7532`（40px，y=104）+ `steps`（14px 三级，y=146）
- 3 统计块 y=196：各 64px 宽，列中心 x=64/120/176：图标 18px + 数字 20px + 单位 12px

### 6. ai（Gemini）
- 顶部：`<` 返回（左 x=20 y=16）+ Gemini 星 32px（居中 y=10）+ `⋮`（右）
- `Gemini`（22px，y=48，居中）
- 回复卡片：x=20 y=78 w=200 h=64，圆角 14，`#1C1C2E`，内文 16px 两行
- 麦克风按钮 56px 圆（中心 (120,196)），蓝紫渐变 + 白麦克风图标 24px
- 事件：点麦克风 3 态链（idle→listening→speaking），speaking 显示波形帧

### 7. settings（设置）
- 标题 `设置`（22px，y=12，居中）
- 4 行（x=16 w=208，高 40，y=46/94/142/190）：
  1. Wi-Fi（蓝圆 24px + wifi 图标）值 `已连接`
  2. 显示（黄圆 + sun）值 `自动`
  3. 声音（紫圆 + volume）值 `70%`
  4. 关于（灰圆 + info）→ 弹层卡片
- 每行：图标圆 24px（x=8）+ 主文本 18px（x=40）+ 值 14px 三级右对齐 + 箭头
- 事件：行点击切换值；关于弹 overlay

## 交互汇总（全部 SquareLine 内置动作）

| 屏 | 事件 | 动作 |
|---|---|---|
| 全部 | GESTURE_LEFT/RIGHT | CHANGE SCREEN（按滑动顺序循环） |
| home | 点 9 圆 | CHANGE SCREEN（无对应屏的 3 个仅视觉反馈） |
| clock | 点表盘 | → home |
| weather | 点主区 | 8 态循环（MODIFY FLAG HIDDEN） |
| ai | 点麦克风 | 3 态链 + 波形帧 |
| settings | 行点击 | 值切换 / 关于弹层 |
